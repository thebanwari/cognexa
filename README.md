# CourseCraft-AI

An AI-powered learning platform that generates personalized courses from any topic.

## Overview

CourseCraft-AI allows users to:
- Enter any topic and generate a complete course curriculum
- Create PDF versions of courses
- Generate assignments, flashcards, and mindmaps
- Ask questions to an AI teacher using RAG technology
- Support for multiple difficulty levels and languages

## Features

### Phase 1 - Core Functionality
- ✅ Course generator (JSON)
- ✅ PDF generator from JSON
- ✅ RAG-powered AI teacher for Q/A
- ✅ Session-based temporary storage

### Phase 2 - Advanced Features
- ✅ Mindmap generator (PNG/PDF)
- ✅ Flashcards generator
- ✅ Assignments generator
- ✅ Study plan generator
- ✅ Difficulty levels

### Phase 3 - Polish & Expansion
- ✅ Voice mode (TTS + STT)
- ✅ Syllabus alignment (upload PDF)
- ✅ User login + saved courses
- ✅ Analytics dashboard

## Tech Stack

- **Backend**: FastAPI
- **Frontend**: Next.js
- **AI**: LLM integration with RAG system
- **Database**: Session-based storage (Phase 1), User accounts (Phase 3)
