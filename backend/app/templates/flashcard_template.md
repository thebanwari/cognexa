# Flashcard Template

This template is used for generating flashcards based on course content.

## Template Structure

### Concept Cards
- **Front**: "What is [Concept]?"
- **Back**: Definition and key characteristics
- **Focus**: Fundamental ideas and principles

### Term Cards
- **Front**: "Define [Term]"
- **Back**: Clear definition with context
- **Focus**: Vocabulary and terminology

### Relationship Cards
- **Front**: "How are [Concept A] and [Concept B] related?"
- **Back**: Connection and interdependence
- **Focus**: Conceptual links

### Example Cards
- **Front**: "Give an example of [Concept]"
- **Back**: Real-world application
- **Focus**: Practical understanding

## Content Areas

1. **Core Concepts**
   - Fundamental principles
   - Key theories
   - Foundational ideas

2. **Important Terms**
   - Technical vocabulary
   - Course-specific language
   - Essential terminology

3. **Relationships**
   - Cause and effect
   - Dependencies
   - Connections between ideas

4. **Applications**
   - Real-world examples
   - Practical uses
   - Case studies

## Generation Guidelines

- Use clear, concise language
- Focus on high-yield information
- Ensure accuracy of definitions
- Include memory aids when helpful
- Organize by topic for easy review
- Create logical groupings
- Maintain consistent formatting
